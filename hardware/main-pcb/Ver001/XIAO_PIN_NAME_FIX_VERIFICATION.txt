SplitChoc64 Ver001 — XIAO nRF52840 Plus pin-name correction review package
==========================================================================

Purpose
-------
Correct schematic/library pin labels for the Seeed Studio XIAO nRF52840 Plus
without changing PCB copper, pad geometry, placement, routing, or 3D models.

Corrected pin names
-------------------
Pad 24: AUX24 -> SWDIO
Pad 25: AUX25 -> SWDCLK
Pad 26: RESET -> EN
Pad 27: GND (unchanged)
Pad 28: AUX28 -> VBAT
Pad 29: AUX29 -> GND

Intentionally NOT changed

- pads 30..33
- PCB routing and net assignments
- all STEP/3D model files
- case/top plate/battery lid/trackball geometry
- ERC/DRC rule settings
