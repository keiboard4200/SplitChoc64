# SplitChoc64 Main PCB Ver012

**Status: manufactured production baseline / frozen geometry**

Ver012 is the reference PCB version for both LEFT and RIGHT halves.

## Fixed geometry

The following must not be changed in later add-on work:

- PCB outline
- key positions
- mating/interlocking geometry between halves

## Intended contents

This directory is the canonical location for the complete Ver012 hardware package, including whenever available:

- KiCad project/source files
- local symbols and footprints
- Gerber and drill outputs
- BOM / position data
- STEP / STL / DXF / SVG references
- manufacturing ZIPs
- ERC/DRC final validation records
- pinout and assembly documentation

The original Ver012 archive should be preserved unchanged alongside any extracted source tree, with its checksum recorded.
