# SplitChoc64 Main PCB Ver000

**Status: manufactured production baseline / frozen geometry**

Ver000 is the formal production version for the first manufactured SplitChoc64 hardware baseline.

This data set was originally developed and manufactured under the internal project label **Ver012**. The design contents are preserved unchanged; only the repository's formal version designation is now **Ver000**.

## Fixed geometry

The following must not be changed in later add-on work:

- PCB outline
- key positions
- mating/interlocking geometry between halves

## Contents

This directory is the canonical location for the complete Ver000 hardware package:

- KiCad project/source files
- local symbols and footprints
- Gerber and drill outputs
- BOM / fabrication data
- STEP references and case data
- manufacturing ZIPs
- validation and design notes
- pinout and assembly documentation

## Legacy naming

Some original filenames and internal documents still contain `Ver012`. Those names are intentionally retained to preserve traceability to the exact files used for the first manufacturing order.

For repository-level versioning:

- legacy `Ver012` = production **Ver000**
- next hardware revision = **Ver001**

The original uploaded archive is preserved under `archive/original-import/splitchoc64_Ver012.zip`.
