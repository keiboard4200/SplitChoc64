# Hardware

This directory contains PCB source data, manufacturing outputs, and hardware-specific documentation.

## Main PCB

`main-pcb/Ver012/` is the frozen production baseline for the manufactured SplitChoc64 PCB.

Do not change:
- PCB outline
- key positions
- left/right interlocking geometry

## Trackball add-on

`trackball-addon/` contains the J4-to-FFC adapter PCB and associated manufacturing/mechanical data for the PAW3222/Torabo variant.

Where practical, keep editable source data and manufacturing outputs together and clearly versioned.
