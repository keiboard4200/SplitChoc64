# 2765 analog joystick — RC5

RC5 adds the two analog axes of the 2765 to the build-proven Ver012 RC4 baseline.

## Right J4 mapping

- J4-1: 3V3
- J4-2: GND
- J4-3: R_JOY_X -> D0 / P0.02 / SAADC AIN0
- J4-4: R_JOY_Y -> D1 / P0.03 / SAADC AIN1
- J4-5: R_JOY_SW -> D2 / P0.28 (reserved in RC5)
- J4-6: R_JOY_SDA -> D4 / P0.04 (free)
- J4-7: R_JOY_SCL -> D5 / P0.05 (free)

RIGHT reads X/Y with the nRF52840 SAADC and sends the analog-stick events over
the split link. LEFT is central and converts them to HID mouse movement.

The 12-bit calibration values are placeholders until the real 2765 can be measured.
RC5 uses an initial 8% deadzone and 8 ms active polling.

JOY_SW is deliberately reserved for the next step; first we compile-prove
ADC -> split -> HID pointer without adding another input path.
