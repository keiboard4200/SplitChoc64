# 2765 analog joystick — RC13 architecture

RC13 replaces the previous analog-stick module with the standard Zephyr/ZMK input pipeline.

RIGHT peripheral:
J4-3 / P0.02 / AIN0 and J4-4 / P0.03 / AIN1
-> zmk,analog-input
-> INPUT_EV_REL / INPUT_REL_X,Y
-> zmk,input-split
-> BLE split transport

LEFT central:
zmk,input-split proxy
-> zmk,input-listener
-> ZMK HID mouse report
-> USB/BLE host

This avoids linking HID endpoint code on the RIGHT peripheral.

Initial analog values are placeholders:
- midpoint: 1650 mV
- usable half-range: 1550 mV
- deadzone: 120 mV
- sample rate: 125 Hz
- scaling: 1/70

These must be calibrated on the actual Adafruit 2765 after assembly.

JOY_SW remains reserved on J4-5 / D2 / P0.28 for the next step.
J4-6 and J4-7 remain unused.
